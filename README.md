# sideNote 📝

一个简洁的 Chrome 侧边栏笔记扩展。点击图标即开侧栏，随手记录，自动保存。

![sideNote](icons/icon128.png)

## ✨ 功能

- **一键侧栏**：点击工具栏图标，浏览器侧边栏即刻打开，边浏览边记录
- **多文档管理**：点 `＋` 直接新建文档，点击标题即可就地重命名，回车跳到正文
- **自动保存**：输入防抖自动保存，无需手动 Ctrl+S
- **时间记录**：每个文档自动记录创建时间和最后编辑时间
- **文档列表**：按创建时间倒序排列，📌 置顶的文档永远排在最前面
- **全文搜索**：支持按标题和内容搜索，命中内容直接显示片段预览
- **批量操作**：勾选多个文档，一键批量导出 / 批量删除
- **导出**：单个文档导出为 `.txt`；多个文档打包为 `sideNoteYYYYMMDD.zip` 一次下载
- **快捷键**：`Ctrl/Cmd + N` 新建，`Ctrl/Cmd + S` 立即保存

## 🔒 完全本地运行

**sideNote 不联网、不上传、不共享你的任何数据。**

- 所有笔记数据保存在浏览器本地的 `chrome.storage.local` 中，仅存在于你这台设备的这个浏览器里
- 没有任何网络请求：没有统计埋点、没有遥测、没有账号系统、没有云端同步
- 扩展申请的权限仅用于核心功能：
  - `sidePanel`：在浏览器侧边栏展示笔记界面
  - `storage`：把笔记保存在本地
- 清除浏览器数据时，笔记会一并被清除；如需留存，请先导出为 `.txt`

导出的 `.txt` 文件保存在你自己的电脑上，是否上传、共享完全由你自己决定。

## 📥 安装

### 方式一：开发者模式加载（当前发布方式）

1. 下载或克隆本项目：

   ```bash
   git clone https://github.com/Shuixingchen/sidenote.git
   ```

2. 打开 Chrome，访问 `chrome://extensions`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择 sidenote 文件夹
5. 点击工具栏中的 sideNote 图标即可使用

> 适用于 Chrome 及基于 Chromium 的浏览器（Edge、Brave 等，界面可能略有差异）。

## 📖 使用说明

| 操作 | 说明 |
|---|---|
| 新建文档 | 顶栏 `＋`，自动命名为「未命名」，直接打字重命名，回车进入正文 |
| 重命名 | 点击顶部标题直接编辑，回车确认 |
| 查看列表 | 左上角 ☰ 汉堡按钮，置顶优先、创建时间倒序 |
| 搜索 | 列表顶部搜索框，匹配标题和正文（不区分大小写） |
| 置顶 | 列表项右侧 📌 或编辑页 ⋮ 菜单 |
| 切换文档 | 顶栏 `∧` `∨` 按列表顺序切换上一篇 / 下一篇 |
| 批量操作 | 列表中勾选文档 → 顶部出现导出 / 删除按钮 |
| 导出 | ⋮ 菜单导出当前文档；列表中勾选多个可批量导出 |

## 📁 项目结构

```
sidenote/
├── manifest.json     # 扩展配置（Manifest V3）
├── background.js     # Service Worker：点击图标打开侧栏
├── sidepanel.html    # 侧边栏界面
├── sidepanel.css     # 样式
├── sidepanel.js      # 全部逻辑（存储、列表、搜索、zip 导出）
└── icons/            # 图标
```

零依赖，无构建步骤，纯原生 HTML / CSS / JavaScript。
